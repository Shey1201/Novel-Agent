# Novel Agent Studio 功能测试指南

## 测试环境准备

1. 确保后端服务运行在 `http://localhost:8000`
2. 确保前端服务运行在 `http://localhost:3000`
3. 打开浏览器开发者工具 (F12)，切换到 Console 标签页
4. 清除浏览器缓存并刷新页面

---

## 一、小说管理功能测试

### 1.1 创建小说
**操作步骤：**
1. 在首页点击 "新建小说" 按钮
2. 填写小说信息：
   - 标题："测试小说-" + 当前时间（如"测试小说-20240309"）
   - 分类：选择任意分类
   - 描述：可选，填写"这是测试小说"
3. 点击 "创建" 按钮

**预期结果：**
- [ ] 页面跳转到小说编辑页面
- [ ] 左侧显示小说标题
- [ ] Console 无错误信息

### 1.2 编辑小说
**操作步骤：**
1. 在小说编辑页面，点击标题旁边的编辑图标
2. 修改标题为 "测试小说-已修改"
3. 点击保存

**预期结果：**
- [ ] 标题更新成功
- [ ] 页面显示新标题
- [ ] Console 无错误信息

### 1.3 删除小说
**操作步骤：**
1. 返回首页
2. 找到刚创建的测试小说
3. 点击删除按钮（或右键菜单）
4. 确认删除

**预期结果：**
- [ ] 小说从列表中消失
- [ ] Console 无错误信息
